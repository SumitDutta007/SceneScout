Promo Finder

Reads a microdrama screenplay and finds 20–60s promo clips: the episode and timestamps for each segment, the hook in the first 3s, the cliffhanger at the cut, and why it works. Ranked in posting order.

Results on I Married a Broken Soldier. He was a Duke (50 episodes)

Hybrid run: rules + Gemini →12 LLM calls, 2.5 min. The LLM judges every episode. Rules-only run →4 seconds, no LLM. Solution doc (PDF) →Approach, scale, cost, evaluation, failures. Evaluation (JSON) →Both runs against 12 moments picked in advance.

Run it on your own scripts (live, rules engine)

Choose a show's episode .txt files (same format as the input pack). They are processed in memory and not stored. The LLM pass isn't run live: it takes minutes and needs a rate-limited API key. Run it from the CLI (--mode hybrid).
